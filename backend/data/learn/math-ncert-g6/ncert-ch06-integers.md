Whole numbers 0, 1, 2, 3, … work well for counting forwards, but real life also needs numbers **below zero** — debts, floors below ground level, temperatures below freezing. **Integers** extend the number line in both directions.

## The need for negative numbers

- Borrowing bananas you don't have → owe **2** → can think of **−2**
- Spending ₹15 when you only have ₹12 → **₹3 due** (debit)

## Integer number line

Mark **0**, then equal steps:

```
… −3  −2  −1   0   1   2   3 …
         ← smaller     larger →
```

- **Positive integers:** 1, 2, 3, …
- **Negative integers:** −1, −2, −3, …
- **Zero** is neither positive nor negative

## Ordering integers

On the number line, a number to the **right** is **greater**.

- 5 > 3 · 0 > −2 · −1 > −4
- Any **positive** integer > any **negative** integer

## Addition of integers

**Same sign:** add the numbers, keep the sign  
−3 + (−5) = −8 · 4 + 7 = 11

**Different signs:** subtract the smaller absolute value from the larger; sign of the bigger number  
−8 + 5 = −3 · 6 + (−4) = 2

**Adding zero:** n + 0 = n

## Subtraction of integers

Subtracting an integer is the same as **adding its opposite**:

**5 − 8 = 5 + (−8) = −3**  
**−3 − (−5) = −3 + 5 = 2**

## Signs in daily life

| Situation | Integer idea |
|-----------|--------------|
| Profit / loss | + profit, − loss |
| Above / below sea level | + above, − below |
| Temperature | + warm, − cold |
| Elevator floors | + up from ground, − basement |
